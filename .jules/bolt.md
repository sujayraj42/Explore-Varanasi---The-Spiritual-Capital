## 2024-05-24 - Avoiding Raw Scroll Position in React State
**Learning:** Storing the raw `window.scrollY` value directly in a React state variable (e.g. `const [scrollY, setScrollY] = useState(0)`) causes continuous, 60fps re-renders of the consuming component and all its children throughout the entire scrolling process, severely degrading scroll performance. React bails out of state updates if the new value is the same as the current value, so returning a threshold-based boolean instead (e.g. `setIsScrolled(window.scrollY > 80)`) effectively stops re-renders once the threshold is crossed, drastically reducing CPU load during scrolling.
**Action:** Always refactor custom scroll hooks to accept a threshold and return a boolean rather than returning raw scroll position integers when the consuming component only needs to toggle UI states based on a threshold crossing.
