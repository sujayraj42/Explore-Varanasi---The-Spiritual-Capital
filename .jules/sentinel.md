## 2026-08-18 - Missing Content Security Policy (CSP)\n**Vulnerability:** The `index.html` file lacked a Content-Security-Policy (CSP) meta tag entirely, despite project documentation suggesting one was enforced.\n**Learning:** This exposes the application to Cross-Site Scripting (XSS) and data injection attacks by allowing resources (scripts, styles, images) to be loaded from any origin.\n**Prevention:** Ensure a strict CSP is implemented by default in the application entry point (e.g., `index.html`), restricting `default-src`, `script-src`, and `style-src` to trusted origins.
